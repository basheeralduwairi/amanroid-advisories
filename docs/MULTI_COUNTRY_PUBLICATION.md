# النشر متعدد الدول — AmanRoid

## المبدأ

تظل التحذيرات منشورة فقط بعد مراجعة بشرية صريحة. تفعيل دولة لا يعني وجود
تحذيرات نشطة فيها؛ بل يفتح مسارها التحريري ويجعل موجزها قابلاً للاستهلاك.
الموجز الفارغ لا يعني غياب التهديدات.

## الملفات

- `countries.json`: manifest عام يحتوي الدول وحالة التغطية والمسارات النسبية.
- `advisories.json`: موجز الأردن القديم للتوافق مع الإصدارات المثبتة سابقاً.
- `feeds/jo.json`: نسخة متزامنة حتمية من موجز الأردن.
- `feeds/<code>.json`: موجز مستقل لكل دولة.
- `feeds/regional.json`: موجز التحذيرات العربية المشتركة.

لا تستخدم روابط كاملة أو مسارات تحتوي `..` في manifest. لا تضع مرشحين أو
مسودات أو سجلات مرفوضة داخل هذه الملفات العامة.

## إضافة تحذير لدولة

1. ابحث يدوياً في مصادر رسمية أو موثوقة، واحفظ المرشح خارج المستودع العام.
2. أضف `source_country` و`geographic_scope` و`affected_countries` عندما تكون
   المعلومات متاحة من الدليل نفسه.
3. استخدم معرفاً دائماً عالمياً، ولا تعيد استخدام معرف دولة أخرى.
4. نفّذ مراجعة خبير صريحة عبر `publish_approved.py`.
5. حدّث موجز الدولة ثم نفّذ:

   ```bash
   python3 scripts/sync_country_feeds.py --write --updated-at 2026-11-18T00:00:00Z
   python3 scripts/validate_multicountry.py
   python3 -m unittest discover -s tests -v
   ```

6. افتح Pull Request. لا يُدمج التغيير إذا فشل فحص JSON أو ظهر سجل غير
   معتمد أو تكرر معرف.

## تفعيل دولة

بعد تجهيز مصادر ومراجعين مستقلين للدولة، غيّر entry الدولة في
`countries.json` إلى `enabled: true` و`coverage_status: active` مع تحديث
`last_reviewed_at`. لا يحتاج AmanRoid إلى إصدار Android جديد؛ يقرأ manifest
بعد التحقق ويحتفظ بآخر نسخة سليمة محلياً.

قبل التفعيل، يجب أن تكون feed الدولة صالحة حتى لو كانت فارغة. لا تُنسخ
تحذيرات الأردن إلى دولة أخرى. التحذير الإقليمي لا يظهر إلا إذا كان نطاقه
الجغرافي يتضمن الدولة المختارة أو كان نطاقه `global`.
